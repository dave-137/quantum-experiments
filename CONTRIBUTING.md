# Contributing

Keep the four study journeys runnable in the same environment. Cite an exact external donor file/symbol for numerical mechanism changes, describe seed and parameter changes, and preserve upstream notices. Add meaningful invariant checks rather than assertions about a preferred result. Keep notebooks thin; generate published outputs from a clean kernel through the proof workflow and retain their execution-revision binding.

This personal repository uses direct commits to `main`, not a required pull-request process. Record affected parameters, test evidence, optimizer stopping details and plot review alongside each scientific update. Run `Simulation proof` manually when computational source changes; output-only and documentation commits do not need a repeated simulation run.
